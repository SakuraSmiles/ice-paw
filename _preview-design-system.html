24. Focus 状态规范

Tab 键聚焦体验：默认隐藏 outline，focus-visible 显示蓝色 ring。

规则：
• 使用 :focus-visible 而非 :focus
• 鼠标点击不显示 ring（focus-visible 特性）
• ring 规格：0 0 0 3px rgba(44,111,238,0.2)
• 按钮额外：outline: 2px solid + outline-offset: 2px
