# 模型配置与降级链

「模型配置」= 厂商 + 模型 + 端点 + API Key 的组合，在**设置 → 模型**页统一管理。它和 agent 解耦：

- **Key 一处换全局生效**：所有引用同一配置的 agent（以及视觉读取、语义检索）共享这一份凭据，换 Key 只改一处。
- 相同的厂商+模型+端点+Key 只会建**一个**实体（自动去重），不会攒一堆重复条目。

## agent 怎么用模型配置

- **新建 agent**：仍是熟悉的表单——选模型、填 Key，保存时系统自动把这套配置收编成模型配置实体，你不用操心。
- **编辑 agent**：只能从已有模型配置里选（不能手改 Key——去模型页改，全局生效）。显示「（配置已删除）」说明引用的实体被删了，重选一个即可。

## 降级链：主力挂了自动换备用

给 agent 配一条**有序的模型配置链**：主力在前、备用在后（在 agent 编辑页的模型区拖拽或键盘调整顺序，第一个是主档）。运行中撞上这些错误会自动切下一档重跑当前回合：

- 余额不足 / 套餐额度用尽（配额类）
- 限流重试耗尽
- 网络错误重试耗尽

**不触发换档**的错误：Key 无效 / 无权限（换档也救不了，直接报错）、内容超长、内容被安全策略拦截——这些直接终止并如实报错。

细节：

- 每次换档会弹「模型已切换」提示，回复来自哪个模型对你是可见的（不会默默降智）。
- 换档**不重置**预算：整次对话的 token 预算跨档累计，防长任务烧穿。
- 链走完还没成功 → 按原始错误终止。
- 委派的子 agent：自己配了链就用自链；没配则继承父 agent 的链。

## 健康状态与测试

模型页每个实体带健康胶囊（状态色点 + 文案，如「正常 / 额度耗尽 / 限流中 / Key 无效」，悬停看最后调用时间与详情）。两个测试入口，用途不同：

- **模型页的「测试」按钮**：验证 Key 与端点配置（鉴权层动作——列得出模型不等于该端点认可对话权益）。
- **agent 编辑页的「测试连接」**（模型区配了链就有）：对 agent 的整条链**逐档真发**一次最小对话请求，能验出「列模型通但对话被拒」的配置（如智谱 Coding 套餐端点不匹配）。

## 删除保护

模型配置被 agent 引用、或被视觉/语义检索配置引用时不能删（提示谁在用）；先解除引用再删。删除实体不影响已完成的会话。

## 常见问题

- **回复突然来自另一个模型？** 触发了降级链换档，看「模型已切换」提示；主力档恢复后下次回合仍从主力起跑。
- **总在换档？** 主力档余额或限流问题，去模型页看健康胶囊的详情。
- **视觉读取 / 语义检索的 Key 在哪换？** 同一处：设置 → 模型。它们的配置也引用模型配置实体。
