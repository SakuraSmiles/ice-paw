# 频道：项目成员协作（群聊）

频道 = **同一项目的全体成员（agent）共用一条消息流**的群聊式协作。你在频道里说话，成员们以聊天软件群聊的方式接话：可以被 @ 点名，也可以由「统筹者」把话题分派给合适的成员。

- **串行圆桌**：一时刻只有一个成员发言，不会抢话；一条消息流全体成员共享。
- **共享记忆**：频道历史对全体成员可见——A 报告过的路径、发现、结论，B 可以直接引用，不用重复劳动。
- 委派和跨会话投递在频道里**刻意禁用**（信息会离开这条共享流），要拉人就在频道里 @。

## 开启与进入

侧栏项目空间下的**「开启频道」**入口（未开启时显示；开启是懒创建，项目刚建立不会自动多出空会话）。开启后侧栏常驻一行，显示「统筹 · 名字」（未选举时「统筹 · 待选举」）。

## 说话的两种方式

- **@ 点名**：输入 `@` 弹出成员候选（标注统筹者/负责人），选中后文本保留 `@名字`。被点名的成员**必须应答**（一次可 @ 多人，上限 5 个；名字要完整精确，重名会被跳过）。
- **广播**（不 @ 任何人）：由**统筹者**接令——它可以直接回答，也可以 @ 更合适的成员分派（它是主持人，不是万能答题机）。

成员回复里也可以 @ 其他成员继续接力；护栏会拦住失控的接力链（见下）。

## 统筹者（主持人）

- **自选举**：统筹空缺时，你发的**第一条广播**触发成员互投，得票最多者当选（平票看加入先后；连不上的成员天然弃权——投票本身就是真实请求，兼任健康检查）。
- **你指定**：频道头部子标题（统筹者名 + 成员头像 + 「共 N 名成员」）点开成员面板，可直接**设为统筹者**，或**罢免**。
- **故障换帅**：系统选出的统筹者连续失败 2 次会被自动罢免，回落到最早加入的成员；**你任命的不自动动**（钦点不擅动），面板里有「让系统补选」出口。

## 护栏（防接力风暴）

一条广播可能引发成员间接力（A 答 → @B → B 答 → @A……），护栏自动拦截：

- 单链连续成员回合 ≤ 8；同一成员对之间来回 ≤ 2 次；成员被唤醒频率 10 分钟内 ≤ 6 次。
- 被拦的接力会在聊天区出通知条（拦了多少、为什么），事实不丢。

## 生成中插话

成员正在生成时你发送的消息**不会丢**：会作为新话题立即排队，等当前生成结束后优先处理（在途的成员接力会被取消）。连发几条会被聚合——稍等约 3 秒一起听，防碎片化打断。

## 归档频道

项目被永久删除后，频道**归档保留**（历史不丢）：只能看不能发，侧栏「已归档」可找到。
