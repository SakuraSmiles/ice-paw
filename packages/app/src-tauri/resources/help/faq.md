# 常见问题（FAQ）

## 对话卡住 / 没响应怎么办

- **点「停止」**：触发取消，已生成的内容会保留。
- **工具一直转圈**：可能 agent 在多轮调工具。有保护机制兜底：
  - 工具轮数上限 `tool_max_rounds`（默认 50）——到了自动停。
  - 停滞检测：连续若干轮没进展会自动终止（`finish_reason=stuck`）。
  - 同错重试熔断：同一个工具错误连犯多次会被纠正或终止（doom 循环保护）。
  - Token 预算 `max_total_tokens`（默认 500k）——超了终止。
- 以上上限都能在 `agent.yaml` 里调（见「agent.yaml 进阶配置」）。

## 怎么停止生成

对话页的**停止按钮**，或对应会话执行停止。会立即中断流式生成，已输出的文本不丢。

## 能发图片吗

能：单张 5 MB 内、单条消息最多 20 张（png / jpg / jpeg / gif / webp）。怎么被「看」取决于模型：视觉模型直读；非视觉模型走**视觉代读**（你配置的视觉模型把图读成文字）。详见「图片与视觉能力」。

## 回复为什么来自另一个模型

agent 配了**降级链**时，主力档撞上余额不足 / 限流 / 网络错误会自动切备用档重跑（有「模型已切换」提示）——长任务不因单档故障中断。详见「模型配置与降级链」。

## Token 预算 / 回答被截断

整次对话有个 token 预算上限（默认 `max_total_tokens: 500000`），超了会终止（`finish_reason=budget_exceeded`），避免长对话失控烧 token。

- 触顶时**默认自动续期**（额度翻倍，至多续 2 次），输入框附近的预算胶囊能看当前用量；不想续期可在 agent.yaml 把 `max_total_tokens` 写成显式硬上限。
- 多轮工具场景提前到顶，直接在 agent.yaml 调大这个值。

## 日志在哪看

**设置 → 日志** 页面可以直接看运行日志。日志按天滚动落盘（tracing daily rotate），排查问题（API 报错、工具失败、钩子执行等）很有用。

## 配置文件在哪

- agent 配置：`<agent 工作区>/agent.yaml`（即时生效，不用重启）。
- 模型配置（Key/端点）：设置 → 模型 页管理，存在应用数据库，Key 加密。
- 知识库文档：`<默认工作空间>/knowledge/`（全局）和 `<agent 工作区>/knowledge/`（agent 专属）。
- 项目上下文：`<默认工作空间>/projects/<项目id>/`（project.md、conventions.md）。
- 共享 Word 模板：`%APPDATA%\com.icepaw.app\templates\`。

详见「项目与 workspace」。

## 工具调用为什么失败 / 被拒

- **授权被拒**：你在弹窗里点了拒绝，agent 会收到拒绝结果。
- **路径不在 workspace**：需要确认；放进 agent/项目 workspace 内可免授权。
- **MCP 连接失败**：外部 server 掉线（会先自动重连一次；持续失败按提示去设置页手动重试）。
- **工具未启用**：会话没开「启用工具」，或 agent 白名单禁用了它。
- 详见「配置 MCP 工具与授权」。

## 换了模型 / embedding 没生效

- 换模型：agent 编辑页选择模型配置；Key 与端点在设置 → 模型 改，一处换全局生效。
- 降级链：想让主力挂了自动切备用，见「模型配置与降级链」。
- embedding 模型：切换会全量重建向量，量大可能几十秒，有二次确认。没配 embedding 则知识库退化为关键词检索。详见「配置知识库与 embedding」。

## 还是搞不定

把「设置 → 日志」里的相关日志带上，描述你做了什么、期望什么、实际什么，便于定位。
