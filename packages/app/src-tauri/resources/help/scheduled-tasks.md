# 定时任务

到点自动执行一轮完整的 Agent 任务（带工具、预算与轨迹）——适合日报、定时检查、周期性巡检等无人值守工作。

## 创建任务

两种方式：

- **设置 → 定时任务 → 新建任务**：填名称、选 Agent、定调度、写提示词，保存即生效；
- **对话里直接说**：对 Agent 说「每天早上 9 点汇总项目进展」，它会调用 `create_scheduled_task` 工具自动创建（也可说「你有哪些定时任务」「把那个任务删了/改成 8 点」）。

调度形态：每天 HH:MM / 每周指定几天的 HH:MM / 每隔 N 分钟（最小 10 分钟）/ 一次性指定时刻 / cron 表达式（6 域含秒，按本地时间，表单实时预览未来三个运行时点）。

## 任务的执行方式

每个任务有自己的**专属会话**（首次执行时自动创建）——历史跨执行累积，Agent 记得上次的结果；每轮执行记录在任务详情的「执行记录」里，可一键跳转会话查看。侧边栏项目切换器的「定时任务」空间汇集全部任务会话。

「立即运行」随时手动触发一次（不影响原计划）。

## 无人值守（进阶）

任务运行时如果没人守着，需要确认的工具调用（如执行命令）2 分钟无人响应会按拒绝处理。任务可配置**预授权**：

- **工具调用照常确认**（默认）：有人在场时用；
- **命令免确认**：执行命令不再弹确认；
- **全部工具免确认**：巡检类重工具任务用（屏幕共享仍走通道治理，不在此列）。

其他进阶项：**错过策略**（应用没开时错过的任务，下次启动补跑一次 / 跳过顺延并记录）、**结果转发**（每轮结果自动投递到指定会话，按目标会话的收件政策处理）。

## 排障

- 任务到点没跑：检查是否已启用、下次运行时间（任务列表可见）；应用没开时按错过策略处理；
- 执行失败：打开任务详情看执行记录的错误信息（常见为 Agent 配置或 API Key 失效——任务不会因此每分钟重试，下一周期再试）；
- 找不到任务会话：任务会话在侧栏「定时任务」空间；删除任务后其会话保留并回到散落会话。
