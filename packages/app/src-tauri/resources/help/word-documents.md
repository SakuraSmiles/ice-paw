# Word 文档能力（读取 · 编辑 · 生成 · 验收）

IcePaw 的 agent 自带一套完整的 Word（.docx）读写能力，不需要额外配置。你能做的：

- 让 agent **读**一份文档并回答结构/内容问题（「这章有几张表」「标题层级是什么」）。
- 让 agent **改**一份文档（改文字、改格式、改表格、增删段落），编辑是「手术式」的——只动目标部位，其余字节原样保留，改动前自动备份。
- 让 agent 按模板**整篇生成**新文档（报告、方案、纪要）。
- agent 生成后**自检验收**，不合格不落盘（你拿到手的都是通过检查的）。

直接在对话里说需求即可，例如「用正式报告模板把下面的内容整理成一份 Word 文档，正文宋体小四」。

## 四类工具（agent 自动选用）

| 工具 | 用途 | 什么时候用到 |
|---|---|---|
| inspect_docx | 读文档 | 查结构、查内容、查格式（大纲/正文/表格/页眉页脚，支持局部区间） |
| edit_docx | 精准编辑 | 在**已有**文档上改：替换文字、增删段落、改段落/表格/单元格格式、合并拆分单元格、删表格行 |
| write_docx | 整篇生成 | 从模板生成**新**文档：标题/段落/表格/目录/图片一次成文 |
| validate_docx | 验收断言 | 生成或编辑后的自检（块数、表格结构、文本、样式等），agent 用它保证结果正确 |

提示：编辑是批事务——一批操作要么全部成功、要么全部不落盘，不会出现改一半的中间状态。

## 模板：write_docx 的起点

`write_docx` 从模板生成完整文档（取代旧的「复制→清空→逐段写」流程），模板按下面的顺序解析，找到第一个存在的就用：

1. **agent 工作区的 `templates/` 目录**（如 `<agent 工作区>/templates/report.docx`）
2. **共享模板目录**：Windows 在 `%APPDATA%\com.icepaw.app\templates\`（安装后自带 `formal-report.docx` 正式报告模板）
3. 内置档位兜底（不写模板名时的默认）
4. 绝对路径（你直接给出某个 .docx 的完整路径）

两个约定值得知道：

- 共享模板目录**存在不动、删了重建**：你可以直接改里面的模板样式（字体、页边距、页眉），IcePaw 永不覆盖你的修改；想恢复出厂版删掉文件重启即可。
- 改模板只影响**之后生成**的文档，已生成的文档不会被回改。

## 样式偏好（word_style_profile）

如果你希望 agent 写 Word 时长期遵循你的格式习惯（如「正文宋体小四、一级标题黑体三号」），不用每次重复说：

- 直接告诉 agent「记住我的 Word 样式偏好：……」，它会写入自己的 `agent.yaml`（`word_style_profile` 字段），之后每次 Word 任务自动带上。
- 也可以自己编辑 agent.yaml（见「agent.yaml 进阶配置」）。

偏好注入的是提示层：agent 会优先按你的习惯选样式、配模板，具体到每篇文档仍可临时覆盖（「这篇用模板默认样式」）。

## 常见问题

- **生成的文档样式不对？** 多半是模板问题：确认用的是哪个模板（说「用共享目录的正式报告模板」），或直接改模板本身。
- **agent 说「文档含活动修订，拒绝编辑」？** 该文档开了 Word 修订（track changes），先在 Word 里接受/拒绝全部修订再交给 agent——这是刻意保护，防止手术编辑与修订标记互相破坏。
- **表格操作被拒绝？** 部分结构性操作（拆分单元格等）要求一批只做这一件事，agent 收到明确错误会自动拆批重试，你不用干预。
- **想留痕？** 生成与编辑都会在会话轨迹里留完整事件流；编辑落盘前有自动备份保护。
