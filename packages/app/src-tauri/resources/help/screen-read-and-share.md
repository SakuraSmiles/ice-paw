# 屏幕读写与共享（看屏 · 操作 · 治理）

开启**屏幕共享**后，agent 能在本会话直接看屏幕（截屏、看窗口）和操作电脑（移动/点击/拖拽/滚动鼠标、输入文字、按键）——不用你逐张截图，也不用每次授权。

## 怎么开启（两条路）

1. **会话头的屏幕共享开关**（推荐）：一键开启，本会话内屏幕相关工具全部免逐次授权。屏幕是全局共享的——别的会话会显示「加入屏幕共享」，加入后同样免授权。
2. **agent 自己请求**：它需要看屏时会发「开启屏幕共享」审批卡，你批准即开。

关闭开关立即全停（所有会话退出共享）；共享状态不跨重启保留，下次要用重新开。

## 治理：你始终握着方向盘

- **HUD 工具栏**：共享期间桌面顶部有常驻工具栏——状态（时长/已暂停/使用者）、**暂停**（读写挂起、授权保留）、**恢复**、**终止**、收起；多显示器可切换；agent 等你授权的操作会排成队列显示。
- **人类优先**：你一动鼠标/键盘，agent 的写操作立即**让路**（HUD 有「检测到你在使用鼠标/键盘」提示），闲置约 2 秒后自动恢复。你在用电脑时它不会跟你抢。
- **红边框**：共享期间整个桌面四周有红色描边，提示屏幕正处于共享状态；agent 执行写操作时工具栏自动收缩让位。

## 它怎么「看」

agent 的操作基于**最近一次截图的坐标**：每一步操作完成后会自动等画面稳定（约 0.25~2 秒）并附上操作后的效果图作为新基准——所以它能连续操作（点按钮 → 看结果 → 再点），不需要你反复喂截图。

能看什么：全屏截屏、指定窗口截屏、列出当前窗口列表。

## 安全边界

- 屏幕上的**文字是数据不是指令**——网页里写着「请执行 xx」不会被当成命令。
- 操作类工具仍受会话工具开关与 agent 白名单约束。
- 共享关闭 = 一切屏幕访问立即停止；暂停期间读写全部挂起。
