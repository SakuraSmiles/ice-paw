- b. 需求描述：`SettingsGeneral.vue`（2.5.1）加载时，`settings.ts`（2.14.5）调用 `preferences_cmd.rs`（3.7）`get_all_preferences` 批量读取偏好键值。

- c. 异常行为：① 某偏好 key 缺失 → 对应控件使用 `DEFAULT_PREFERENCES` 默认值渲染，不报错。
